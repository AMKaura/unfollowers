# unfollowers
Open-source code to see who unfollowed you!

Tutorial()
1. Clone or download the repository into your local environment
2. Export your followers and following all time information from instagram in JSON (https://help.instagram.com/181231772500920/)
3. Move followers_1.json and following.json into the same folder as the repo files
4. open the terminal in the folder the files are in
5. run py -m http.server 8000 or python3 -m http.server 8000
6. open http://127.0.0.1:8000/ in your browser of choice

The list may contain deactivated accounts because of old information from Instagram
